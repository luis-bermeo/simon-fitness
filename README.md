# Simon Fitness — Servicio Técnico de Maquinaria de Gimnasio

Sitio web profesional para **Simon Fitness**, empresa de servicio técnico especializado en reparación, mantenimiento, instalación y asistencia técnica de maquinaria de gimnasio en **Murcia y Alicante**.

## 🛠️ Tecnologías

- **HTML5** semántico
- **CSS3** puro con Variables CSS (Custom Properties)
- **JavaScript Vanilla** (sin frameworks ni librerías)
- Diseño **Mobile-First** y 100% responsive

## 🎨 Diseño

- Estética premium inspirada en Apple/Stripe
- Fondo claro con acentos en Rojo Eléctrico (#E30613)
- Efectos Glassmorphism, micro-animaciones y transiciones suaves
- Tipografía Inter (Google Fonts)

## 📁 Estructura

```
simon-fitness/
├── index.html          # Página principal completa
├── css/
│   ├── variables.css   # Sistema de diseño (variables CSS)
│   └── style.css       # Estilos globales y componentes
├── js/
│   └── script.js       # Interacciones y animaciones
└── img/
    └── hero-technician.png
```

## ✨ Características

- Navbar inteligente (se oculta/muestra con scroll)
- Menú hamburguesa responsive
- Scroll Reveal con Intersection Observer API
- Botón flotante de WhatsApp con badge animado
- Formulario de contacto preparado para EmailJS
- Datos estructurados JSON-LD (Schema.org LocalBusiness)
- SEO técnico optimizado

## 🚀 Cómo usar

Abre `index.html` con Live Server o Live Preview para ver el sitio funcionando.

## 📍 Zona de servicio

Región de Murcia y Provincia de Alicante, España.
